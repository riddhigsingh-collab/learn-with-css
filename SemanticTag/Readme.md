# Naming Conventions in Programming

Naming conventions are rules used to name variables, functions, classes, constants, and files in a consistent and readable way.

## 1. camelCase

The first word starts with a lowercase letter, and every subsequent word starts with a capital letter. There are no spaces or separators between words.

**Examples:**
- `userName`
- `totalAmount`
- `calculatePrice()`

**Commonly used in:** JavaScript, Java, and C++.

## 2. PascalCase

Every word starts with a capital letter. There are no spaces or separators between words.

**Examples:**
- `UserProfile`
- `PaymentGateway`
- `StudentDetails`

**Commonly used for:** Classes, constructors, and components.

## 3. snake_case

All words are written in lowercase and separated by underscores (`_`).

**Examples:**
- `user_name`
- `max_limit`
- `total_amount`

**Commonly used in:** Python, Ruby, and database naming.

## 4. kebab-case

All words are written in lowercase and separated by hyphens (`-`).

**Examples:**
- `main-header`
- `font-size`
- `user-profile`

**Commonly used in:** CSS class names, URLs, and file names.

## 5. UPPER_SNAKE_CASE

All letters are uppercase, and words are separated by underscores (`_`).

**Examples:**
- `MAX_RETRIES`
- `API_KEY`
- `DEFAULT_TIMEOUT`

**Commonly used for:** Constants and environment variables.

## Quick Comparison

| Naming Convention | Example | Separator |
|---|---|---|
| camelCase | `userName` | None |
| PascalCase | `UserProfile` | None |
| snake_case | `user_name` | Underscore (`_`) |
| kebab-case | `main-header` | Hyphen (`-`) |
| UPPER_SNAKE_CASE | `MAX_RETRIES` | Underscore (`_`) |

## Conclusion

Using consistent naming conventions makes code easier to read, understand, maintain, and collaborate on. Different programming languages and projects may follow different conventions, so always check the relevant style guidelines.
